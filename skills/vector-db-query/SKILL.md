# vector-db-query

## 目标
当用户询问关于公司内部政策、特定产品细节、历史事件或非通用知识时，不要试图用你自己的训练数据去回答这些具体问题，而是先检索。

## 工作流程分为三步：

### 1. 分析用户意图与关键词提取
   - 分析用户的自然语言问题。
   - 提取核心关键词（例如：将“XXX是什么意思”提取为“XXX 意思”）。
   - 如果用户的问题含糊（例如“我想请假”），将其转化为查询词“请假流程 制度”。

### 2. 执行向量检索
   - 使用 `get_similar_docs(query="提取的关键词")` 工具。
   - 确保查询语句是陈述句或关键词组合，而非疑问句，以提高检索准确率。

### 3. 综合回答
   - 检查检索到的上下文（Context）。
   - 如果检索结果为空，回答：“抱歉，我在知识库中未找到相关信息。”
   - 如果检索到信息，结合上下文和你的语言能力，组织一个通顺、准确的回答。
   - **重要**：严格基于检索内容回答，不要编造数据。
