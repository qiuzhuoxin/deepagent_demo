# query-writing

## 生成sql流程
1. 根据用户问题获取涉及的相关表结构和相似问题的sql问答对
2. 使用工具 _get_similar_ddl 获得相关表结构
3. 使用工具 _get_similar_sql 获得相关的问答对提示
4. 参考sql生成指南
5. 最后使用工具 _execute_sql 执行sql语句

## 生成指南
1. 如果问题在历史中已经被问过并回答过，请优先考虑历史问答的内容，此时可无需考虑表结构的定义。
2. 如果提供的上下文足够，请为问题生成有效的SQL查询，无需任何解释。
3. 如果提供的上下文不足，请解释为什么无法生成。
4. 请使用最相关的表。
5. 确保输出的SQL符合达梦数据库（DM8）规范，可执行且无语法错误。
